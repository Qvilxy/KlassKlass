# Klass.Klass

Приложение для обмена заданиями между студентами и преподавателями.

## Установка базы данных

1. Откройте SQL Server Management Studio (SSMS)
2. ПКМ по папке **Databases** → **Import Data-tier Application**
3. Выберите файл `klassklass.bacpac`
4. Нажмите **Finish**

## Запуск проекта

Откройте `KlassKlass.sln` в Visual Studio и нажмите **F5**.
